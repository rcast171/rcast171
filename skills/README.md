Copy the desired folder into your agent’s supported skills directory. Read its SKILL.md before use. These skills require the relevant file, browser, or connector capabilities for the task; instructions alone do not provide those integrations.

Validation: all seven passed structural validation and synthetic scenario checks on 6 October 2026. This is not a claim that every integration or future task has been tested. Existing user authorization takes precedence over unnecessary repeat approval.
