# Reconcile professional profiles




Follow the user’s approved scope. Preserve unresolved conflicts and report only observed actions and checks. Complete preparation before requesting any necessary review. Existing authorization remains valid; do not request approval again for an already approved action. A completed draft alone is not authorization to publish, install, or send.

1. Read the current résumé and existing public profiles where available. Create a shared fact register for dates, titles, names, metrics and credentials.
2. List material contradictions without silently choosing a preferred number. Preserve current-source wording while flagging unresolved accuracy.
3. Verify certificates using actual award records/credential links; course enrollment is not completion and course completion is not production expertise.
4. Tailor emphasis to target roles while retaining accurate scope; do not narrow a broad approved career search to AI alone.
5. Map each featured capability to a demonstrable project and link. Avoid repeating company outcomes as personal ownership or project results.
6. Draft minimal aligned changes and show exact replacements; apply external edits when authorized.

Required output: Cross-profile consistency matrix and reviewed replacement copy.

Behavior check: Résumé summary says 100+ sales and a bullet says 150+. Flag one underlying count to reconcile; do not blend or inflate.
